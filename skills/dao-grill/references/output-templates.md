# dao-grill 输出模板

## 模板 A：最小通用版

```md
【当前理解】
我当前理解这轮主要是在做：`[一句话任务]`
现在最容易跑偏的地方是：`[一句话风险]`
所以我先围绕目标、边界、验收来 grill。

【Dao Grill】
目标：`[这轮真正要成立的事]`
边界：`[做到哪为止]`
不做：`[这轮明确不做]`
风险：`[最容易翻车的点]`
验收：`[做到什么算过门]`
下一步：`[当前最合适的第一步]`

【过门判断】
`[可开工 / 需补一问 / 暂不建议开工]`
原因：`[1 到 2 句说明]`
```
