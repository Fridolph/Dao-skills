# Dao Commit 六十四卦选择检查（首轮确认）

## 用法

这份索引是 `dao-commit` 的选卦权威入口。

先以本次集成单元相对基线的**整体处境与净变化**筛选候选卦，再以本表的选择检查排除误配，最后才用上下卦解释结构。`type` 只记录具体行为，不触发卦名。

若缺少完整证据，不强行定卦；应保留为候选，或改用普通 Conventional Commit。

| 卦 | 选择检查 |
|---|---|
| 乾 | 主动开出并持续维持可自强的整体秩序；目录、体量或“从零开始”不足以成立。 |

| 屯 | 主线初生、风险或条件交错，本次立起最小秩序或可推进通路。 |
| 蒙 | 关键未知原本不能诚实定义，本次将其澄清为可讨论、可验证或可决策的边界。 |
| 需 | 已知关键条件尚缺，明确等待条件、复看点与等待期间的必要准备。 |
| 讼 | 责任、契约或风险判断真实相背，且不裁断会扩大损害；本次形成可执行裁决与责任边界。 |
| 师 | 面对险事的集体行动，同时具备主事者、纪律或协同规则、行动节奏与验收。 |
| 比 | 可说明归向何处、该中心为何值得长期信赖；不可用一次共事或汇聚代替长期归向。 |
| 小畜 | 所蓄之力尚小且未成势，能说明前置条件、未来出口与尚不能扩张的约束。 |

| 泰 | 原本分隔的关键层次形成真实双向交换与可验证共同流转。 |

| 同人 | 有公开共同目标、独立角色共同承担与守正协作规则。 |
| 大有 | 足以影响整体的能力或资源已形成可治理、可分配、可承担的“所有”。 |
| 谦 | 有真实能力或成果，却主动降低炫示、越位或中心化，使其归于整体秩序。 |
| 豫 | 明确目标、可动员参与者与资源，已经形成实际行动的准备条件。 |
| 随 | 顺合可辨认且已确认的正当主势，同时保留边界与验证。 |
| 蛊 | 长期积弊已造成失序，本次完成辨因、专项整治与防复发安排。 |
| 临 | 明确承接对象被正式纳入治理，且有 owner、治理方式与时限或复看机制。 |
| 观 | 有可信全景证据、明确判断问题与口径，尚未转入实施或定案。 |

| 贲 | 已有正确稳定之质，本次只作有限文饰以提升可读、可辨或可用，不改本。 |
| 剥 | 支撑已失、正在剥落或不得不去；本次削减失支之层并护住核心。 |
| 复 | 能给出“原锚点 → 偏离证据 → 回归方式”的三段证据。 |
| 无妄 | 识别虚假前提、侥幸判断或无根据干预，并使决策重新服从事实与正当目的。 |
| 大畜 | 可涉大事之力被纪律、边界和训练涵养，能说明后续所涉与建立的承载能力。 |

| 未济 | 仅在本次 Dao Commit 界定的集成单元内：主体已通，剩余条件直接决定最终过门，且收口责任明确。 |

## 近义复核

- `需 / 未济`：条件尚缺的守时，和主体已通但临门未过，不可混用。
- `讼 / 睽`：必须裁断的相背，和承认差异下的有限协作，不可混用。
- `履 / 坎 / 小过`：近险守分、重险成通、小处例外，分别判断。
- `观 / 蒙 / 临`：建立全景、澄清关键未知、正式承接治理，分别判断。
- `泰 / 否 / 晋 / 明夷`：流转通塞与明暗处境，均非普通联调、页面或文档的同义词。
- `离 / 贲`：依实显明，与不改本的文饰，不可混用。
- `既济 / 未济`：仅指本次集成单元的过门，不等于普通 `fix` 的完成与未完成。
