# dao-handoff 示例集

## 示例 1：窗口切换时的中断续跑

### 对方说

> 这个窗口先关了，你给我一个 handoff，下一次我继续做。

### 更好的输出方向

```md
【接棒】我接的是 `dao-grill` 初版 skill，我下一步先补剩余 flow skills。

【Handoff】
目标：先把 `Dao Flow Skills v0.1` 三件套补齐
当前状态：in-progress
已完成：`dao-grill` 已落 skill、模板、示例
下一步：补 `dao-handoff` 与 `dao-review`
阻塞：暂无硬阻塞，主要是保持范围不要扩成完整 skill 家族
自测：文本结构已检查，`git diff --check` 已过
文档锚点：`99-藏-归档与候选/00-方案草案/2026-06-03-Dao-Flow-Skills-v0.1实践候选.md`
集成锚点（如适用）：不适用；本轮完成后使用普通 `docs` 提交
```

## 示例 2：换模型前交棒

### 对方说

> 换个更擅长代码的模型继续，你先把当前状态交清。

### 更好的输出方向

重点不是复述刚才全部讨论，而是交清：

- 当前主线
- 已完成什么
- 下一步先做哪一步
- 哪些风险不要踩

## 示例 3：交给下一位 review

### 对方说

> 这轮我自己改完了，你帮我给下一位一个 review-ready handoff。

### 更好的输出方向

```md
【接棒】我接的是 `[...]` 这一轮 review-ready 交接，我下一步先看风险与验收。

【Handoff】
目标：确认这轮是否可收口
当前状态：review-ready
已完成：`[...]`
下一步：review 风险、验收、自测证据
阻塞：`[...]`
自测：`[...]`
文档锚点：`[...]`
待确认：`是否需要补文档 / 是否位于集成边界`
集成锚点（如适用）：`[...]`
```
