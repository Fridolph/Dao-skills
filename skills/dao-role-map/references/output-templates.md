# dao-role-map 输出模板

这份文档提供 `dao-role-map` 的可复用回答模板。

它不是新的规则，只是把 `SKILL.md` 里已经确定的归位结构，整理成更方便直接说出口的样子。

## 使用提醒

套模板前，先确认三件事：

- 现在真的是在问“这些事分别是什么身份”
- 当前问题是主线失焦或同级冲突，不是执行排程
- 你不会一上来就给任务清单，而跳过归位

如果这三件事还没成立，先回到 `SKILL.md`，不要直接套模板。

## 模板 A：完整 6 段式通用模板

```md
### 1. 当前总判断
你现在的问题，不是事情太多，而是 `[事项 A / 事项 B / 事项 C]` 都在争同一级主位。
这一步先不急着谈先做什么，而是先把这些事放回它们在 Dao 里的位置。

### 2. 归位原则
这次我用 `养分 -> 根 -> 干 -> 枝 -> 叶` 来归位：
- 养分：`[学习 / 输入 / 能量来源]`
- 根：`[定义 Dao 是什么]`
- 干：`[稳住 Dao 进入实践]`
- 枝：`[从 Dao 长出的项目 / 验证场]`
- 叶：`[对外表达 / 展示 / 传播]`

### 3. 身份归类
- `[事项 1]` -> `[养分 / 根 / 干 / 枝 / 叶]`，因为 `[原因]`
- `[事项 2]` -> `[养分 / 根 / 干 / 枝 / 叶]`，因为 `[原因]`
- `[事项 3]` -> `[养分 / 根 / 干 / 枝 / 叶]`，因为 `[原因]`
`[继续补充更多事项]`

### 4. 当前阶段优先级
按你现在这个阶段，我会把优先级看成：`[例如：根 > 干 > 枝 > 叶]`
这不是价值高低，而是当前时位判断。

### 5. 风险提醒
这一步最容易出现的偏差是：`[把枝抬成根 / 把叶推到前面 / 把学习误当建造 / 把所有事情都放同级]`

### 6. 下一步建议
1. `[下一步建议 1]`
2. `[下一步建议 2]`
3. `[下一步建议 3，可选]`
```

## 模板 B：事情很多、都很重要时

```md
### 当前总判断
你现在不是在推进很多同级项目，而是在培育一个母体，同时让若干事情围着它生长。
真正让你累的，不只是事情多，而是它们暂时都挤在同一个平面上。

### 归位原则
这次先用 `养分 -> 根 -> 干 -> 枝 -> 叶` 把它们拆开，看谁在滋养、谁在定义、谁在稳固、谁在验证、谁在表达。

### 身份归类
- `[学习易经 / 学习 AI]` -> 养分
- `[Dao 母体定义 / L1-L6 梳理]` -> 根
- `[Dao Commit / 中轴方法]` -> 干
- `[听澜 / openclaw-temp]` -> 枝
- `[个人主页 / 对外表达]` -> 叶

### 当前阶段优先级
如果母体还在成形，通常先守住根和干，再放枝和叶舒展。

### 风险提醒
最容易出现的偏差，是因为每件事都重要，就让每件事都来争当前主位。

### 下一步建议
1. 先写一句当前阶段主线
2. 再给每件事补一句“它在服务哪一层”
3. 最后才进入执行排序
```

## 模板 C：新方向进入体系时

```md
### 当前总判断
这一步先不要急着决定这个新方向做不做，而是先判断它在 Dao 里属于什么位置。

### 归位原则
新东西进入体系时，先看它是在定义母体，还是从母体长出来。

### 身份归类
- 如果它在定义通用判断、流程、理论：更接近根或干
- 如果它是具体项目、产品、验证场：更接近枝
- 如果它主要承担展示、传播、连接：更接近叶

### 当前阶段优先级
先定身份，再定推进速度；先判断它服务哪一层，再决定它应不应该现在往前推。

### 风险提醒
最容易出现的偏差，是把每个新想法都误抬成母体建设。

### 下一步建议
1. 先给这个新方向补一句“它在验证或服务 Dao 的哪一层”
2. 再决定它当前是否该推进
3. 不要直接跳进实现细节
```

## 模板 D：叶子争主位时

```md
### 当前总判断
这次不是在否定 `[主页 / 表达 / 展示]` 的价值，而是在判断它现在是不是被推到了过前的位置。

### 归位原则
表达类事项通常是叶。叶不是不重要，但当根和干还没稳时，它不应该争主位。

### 身份归类
- `[个人主页 / 对外内容]` -> 叶
- `[Dao 定义 / 母体结构]` -> 根
- `[中轴方法 / 协作骨架]` -> 干

### 当前阶段优先级
如果母体还在成形，根和干优先于叶。
这不是价值否定，而是时位判断。

### 风险提醒
最容易出现的偏差，是让外化表达早于内部结构成形。

### 下一步建议
1. 先把叶子的任务定义成“服务母体可见性”
2. 不把它当成当前主线
3. 等根和干稳一点，再让它展开
```

## 模板 E：日常对话轻量版

适合对方临时问一句，你不想一下子展开成长文时使用。

```md
这次我先不急着回答先做什么，先只做一件事：把 `[事项们]` 放回它们在 Dao 里的位置。

我当前的判断是：
- `[事项 A]` 更像 `[养分 / 根 / 干 / 枝 / 叶]`
- `[事项 B]` 更像 `[养分 / 根 / 干 / 枝 / 叶]`
- `[事项 C]` 更像 `[养分 / 根 / 干 / 枝 / 叶]`

所以你现在真正要守的主线是：`[一句话主线]`

这一步最大的风险，不是事情少做一点，而是让不同层的事一直挤在同一平面上。

所以我建议下一步先：`[一句话建议]`
```

## 一句话原则

模板只是帮归枢把话说稳，不能替代归位本身。

真正要守住的只有三件事：

- 先归位
- 再看当前阶段主线
- 不把执行顺序误抬成身份判断
